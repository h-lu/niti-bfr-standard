# 最小方案设计

## 1. 为什么先选单一几何量 `x(T)`

对于“弯曲针头恢复到直”的第一阶段，最重要的是让算法链路稳定、单调、可解释。

因此不先追求完整曲率场，而是先追求一个:

- 从视频中容易提取
- 与恢复程度单调对应
- 对噪声和局部遮挡不太敏感

的标量几何量。

这里在仓库里进一步细化为四条几何量:

- `x_route_a(T) =` 路线 A 直接端点检测得到的弦长
- `x_fit(T) =` 拟合曲线固支端到自由端的弦长
- `kappa_fit(T) =` 单弯段拟合得到的等效曲率
- `x_route_c(T)` / `kappa_route_c(T) =` 路线 C 在时间连续性约束下得到的增强量

原因:

1. 物理上，针头长度近似不变，恢复到直时 `x(T)` 会逼近真实长度 `L`
2. 图像上，直接端点法最直观，但整形状拟合通常更稳
3. 对单弯恢复，`x_route_a(T)`、`x_fit(T)`、`kappa_fit(T)`、`x_route_c(T)` 和 `kappa_route_c(T)` 都能与“直化程度”建立单调对应

这里需要特别区分三条路线的角色:

- 路线 A: 标准/工程基线
  对应“恢复位移 vs 温度”的大框架
- 路线 B: 论文主方法
  对应“整条形状 + 低阶拟合曲率”的主线
- 路线 C: 工程增强方法
  对路线 B 加时间连续性，不改变其物理定义

## 2. 最小物理模型

针头被建模为二维平面中的不可伸长细杆，近端固支，自由端无外载。

第一阶段不直接求解完整热-力耦合，而是用一个符合恢复规律的低维代理模型:

1. 形状由单一曲率参数 `kappa(T)` 控制
2. `kappa(T)` 随温度升高单调下降
3. 转变区呈 S 形变化

可写成:

`kappa(T) = kappa_A + (kappa_M - kappa_A) / (1 + exp((T - T0) / w))`

其中:

- `kappa_M` 是低温弯曲态曲率
- `kappa_A ~ 0` 是高温直态曲率
- `T0` 是主转变中心
- `w` 控制转变带宽

## 3. 由模型到合成视频

系统测试和校准需要“有真值”的视频，所以最小仓库必须能自己生成:

1. 温度轨迹 `T(t)`
2. 每帧针头中心线
3. 对应图像帧
4. 真值 `x(T)` 和 `R(T)`

第一版视频只需要满足:

- 构型与 `wire-like.mp4` 接近: 上端固定、针体向左下方弯曲
- 分辨率和视场比例接近
- 可加入少量模糊、噪声和亮度漂移

## 4. 最小视频分析链

当前真实视频分析链的最小主线为:

1. 选定 ROI
2. 灰度化 + 模糊
3. 阈值提取暗色针体
4. 取主连通域和主轮廓
5. 路线 A: 直接从主轮廓提取固定端与自由端，输出 `x_route_a`
6. 路线 B: 从主区域采样中心线点，并对单弯段做二次曲线和圆弧拟合
7. 路线 C: 在路线 B 结果上加入端点弱约束与时间连续性
8. 输出 `x_fit`、`kappa_fit`、`x_route_c` 与 `kappa_route_c`

这不是最终的工业级算法，但足够作为:

- 仓库骨架
- 合成数据回归测试
- 早期参数讨论载体

## 5. Af 指标策略

完整实验中:

- `Af-95` 直接由 `R(T)=0.95` 求得
- `Af-tan` 用主转变段最大斜率切线与高温平台交点求得

对不完整视频:

- 不把输出视为正式材料参数
- 只输出 `x(t)` quicklook 或基于外部高温参考的暂估值

## 6. 为什么这套方案适合作为第一版

因为它同时满足 3 个要求:

1. 能落地: 很快能形成可运行仓库
2. 物理上不乱来: 长度守恒、恢复单调、平台明确
3. 易扩展: 后续可替换成更高保真中心线和温度同步模块
