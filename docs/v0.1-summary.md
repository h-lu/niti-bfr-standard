# v0.1 封版结论

更新时间: 2026-04-18

本文档用于把当前仓库在“单根弯曲针恢复到直”这一类对象上的阶段性结论收口，作为最小可交付版本 `v0.1` 的说明。

## 1. 当前对象是否算“已解决”

可以认为:

- 对这类单根、单主弯段、近端固定、平面内恢复到直的针型对象，
- 当前仓库已经完成了“最小可行方案”。

更准确地说，当前已经解决的是:

1. 合成 demo 的物理启发模型、视频生成和真值基准
2. 路线 A / B / C 三条算法链路
3. 从视频提取 `x(T)`、`kappa(T)` 并计算 `Af-95` / `Af-tan`
4. 对真实视频 `wire-like.mp4` 的 quicklook 和 QC 可视化
5. 对三条路线的定位与推荐主量判断

当前还没有完全解决的是:

1. 真实实验视频的温度同步
2. 完整高温平台下的正式 `Af` 输出
3. 多段真实同类视频上的鲁棒性验证

所以:

- 从“最小方案仓库”角度看，已经基本做成
- 从“正式实验测量工具”角度看，还差实验闭环

## 2. A / B / C 三条路线的当前定位

### 路线 A

定位:

- `standard-aligned displacement baseline`

当前定义:

- 以轮廓/针尖 apex 主导
- 直接测固定端到自由端弦长 `x_route_a(T)`

优点:

- 直观
- 工程上最好解释
- 作为 quicklook 和基线很合适

当前结论:

- 已经达到“可用单帧基线”的程度
- 但它仍然依赖轮廓质量，不建议单独作为长期主方法

### 路线 B

定位:

- `literature-aligned primary method`

当前定义:

- 用主骨架/中心线路径定义 `x_fit(T)`
- 用主弯段低阶拟合定义 `kappa_fit(T)`

优点:

- 最贴近非接触 BFR 论文主线
- `kappa_fit(T)` 物理意义清楚
- 更适合长期做正式主方法

当前结论:

- `kappa_fit` 已经比较成熟
- `x_fit` 经过单独优化后，已经和路线 A 解耦，并能稳定代表“中心线长度量”

### 路线 C

定位:

- `engineering temporal enhancement`

当前定义:

- 以 A/B 的单帧几何结果为观测
- 在时间轴上构造最小几何状态:
  - `anchor`
  - `axis theta`
  - `x`
  - `kappa`
- 经过时间正则后输出 `x_route_c(T)` 和 `kappa_route_c(T)`

当前结论:

- 它已经不只是“数值平滑”
- 而是“最小时序几何状态版”
- 当前最推荐的 Af 主量是 `kappa_route_c(T)`

## 3. 当前推荐用法

### 3.1 如果只想快速看视频有没有恢复

优先看:

- 路线 A 的 `x_route_a(t)`
- 路线 C 的 `x_route_c(t)`

原因:

- 直观
- 容易和肉眼观察对应

### 3.2 如果要做当前仓库里的正式主结果

优先看:

- 路线 C 的 `kappa_route_c(T)`

原因:

- 在当前 demo 基准上，它对 `kappa_true(T)` 的 `Af-95` / `Af-tan` 误差最小
- 同时具备时间稳定性

### 3.3 如果要对照文献主线

优先看:

- 路线 B 的 `kappa_fit(T)`

原因:

- 它最接近“整条形状 + 低阶拟合曲率”的论文主方法

## 4. demo 的理论值

当前 demo 有两套真值:

### 4.1 `x_true(T)` 对应真值

- `x_af95_c = 49.641124`
- `x_aftan_c = 48.719700`

### 4.2 `kappa_true(T)` 对应真值

- `kappa_af95_c = 52.884011`
- `kappa_aftan_c = 50.995924`

因此:

- 比较 `x_route_a / x_fit / x_route_c` 时，应对照 `x_true`
- 比较 `kappa_fit / kappa_route_c` 时，应对照 `kappa_true`

## 5. 当前版本下的推荐主量

当前最推荐的 Af 主量是:

- `kappa_route_c`

原因不是“它看起来最平滑”这么简单，而是:

1. 它有清楚的曲率物理意义
2. 它符合路线 B 的物理定义
3. 它在路线 C 的时序状态增强下更稳定
4. 它在 demo 基准中和 `kappa_true` 最接近

## 6. 当前真实实验输入要求

要把当前仓库从“最小方案”推进到“正式实验输出”，至少还需要下面这些真实输入。

### 6.1 必需输入

1. 视频文件
   当前对象仍限定为单根弯曲针恢复到直
2. 同步温度序列
   至少需要 `time_sec, temperature_c`
3. 尽量完整的恢复过程
   包括低温起始段和高温平台段

### 6.2 推荐输入

1. 固定拍摄视场和夹具布局
2. 稳定照明和较干净背景
3. 至少 2 到 3 段同类真实视频
   用来验证鲁棒性不是只对一个样例成立
