真实分析工作流

上传视频，比较 A / B / C，统一在结果页复核。

首页只保留真实视频分析需要的最小输入。你可以选择对象类型、填写任务名称、上传视频、设置抽帧步长， 如果有同步温度数据，再附带 CSV。系统会在结果页统一展示对象级摘要、A / B / C 路线卡片、标注视频和下载产物。

01 提交输入 选择 `wire-like` 或 `braided-like`，上传视频并设置抽帧步长。
02 判断流程 没有温度 CSV 时按 quicklook 进入；有温度同步时走 formal Af 提交流程。
03 回看结果 在详情页统一查看对象级结果、路线差异、QC 图像和标注总览视频。
